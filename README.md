# Grounded Mortgage Assistant

A mortgage chat assistant that answers only from reviewed, cited sources, calculates loan-to-value through a tool call, and turns a conversation into an editable application draft.

## Provenance

This history is a curated re-creation. The project was developed from 29 to 31 October 2026 in a private repository that also held Lendo-owned content, which cannot be published. These commits were assembled on 31 October 2026 from that final state, in dependency order; they do not reproduce the original sequence.
